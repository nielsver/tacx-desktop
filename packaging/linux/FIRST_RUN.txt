Tacx Desktop — Linux first-run (Garuda / Arch primary)
======================================================

1) BlueZ session (never sudo the app)
   sudo pacman -S --needed bluez bluez-utils bluez-libs gtk3 libepoxy xz util-linux
   sudo systemctl enable --now bluetooth
   groups | grep -q bluetooth || sudo usermod -aG bluetooth "$USER"   # then log out/in
   rfkill unblock bluetooth 2>/dev/null || true
   bluetoothctl power on
   bluetoothctl show | grep -E 'Powered|Discovering'

2) Extract the Release tar.gz (keep the whole tree)
   mkdir -p ~/Apps
   tar -xzf tacx-desktop-linux-x64-*.tar.gz -C ~/Apps
   cd ~/Apps/tacx-desktop
   chmod +x ./tacx_desktop
   ls lib | grep -i tacx_desktop_core

3) Runtime libs
   ldd ./tacx_desktop | grep 'not found' || echo "ldd OK"
   # If anything is missing: sudo pacman -S gtk3 libepoxy xz util-linux

4) Run from this directory (RPATH $ORIGIN/lib finds libtacx_desktop_core)
   ./tacx_desktop
   # Only if you see "error while loading shared libraries":
   #   export LD_LIBRARY_PATH="$PWD/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
   # Wayland blank/crash fallback:
   #   GDK_BACKEND=x11 ./tacx_desktop

   Optional: add "Tacx Desktop" to the KDE app menu (user-only, ~/.local):
     ./install.sh        # remove again with ./uninstall.sh

5) In-app
   Demo ON → ERG / Resistance / Intervals / Simulation (includes DEMO KICKR CORE)
   Demo OFF → quit Zwift/Tacx/MyWhoosh/Wahoo/Rouvy → forget trainer in KDE Bluetooth
   (do NOT OS-pair) → Scan (Tacx or Kickr FTMS) → Connect → ERG. UI must stay responsive while Connecting.

Pitfalls: Soft-blocked rfkill; OS pairing; another app holding the link (busy/NOCTRL — quit Wahoo app too).
Kickr ERG: allow 3–5 s to settle after Apply. Kickr Bike: Resistance panel stays disabled (ERG/Simulation only).
Public FTMS only — no Wahoo proprietary a026* path.
