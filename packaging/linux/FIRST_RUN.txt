Tacx Desktop — Linux first-run (Garuda / Arch primary)
======================================================

Pick one install path (AppImage is the easiest one-click on Garuda):

A) AppImage (recommended — no root)
   chmod +x Tacx_Desktop-*-x86_64.AppImage
   ./Tacx_Desktop-*-x86_64.AppImage
   # Optional: move to ~/Applications and add a menu entry via your DE,
   # or keep using the AppImage launcher as-is.

B) .deb (Debian/Ubuntu and some Arch helpers)
   sudo pacman -S --needed debtap   # Garuda/Arch optional
   # Debian/Ubuntu:
   sudo apt install ./tacx-desktop_*_amd64.deb
   # Then find "Tacx Desktop" in the app menu, or: tacx-desktop

C) tar.gz + launcher (works everywhere BlueZ runs)
   mkdir -p ~/Apps
   tar -xzf tacx-desktop-linux-x64-*.tar.gz -C ~/Apps
   cd ~/Apps/tacx-desktop
   chmod +x ./tacx_desktop
   ./install.sh          # adds "Tacx Desktop" to the KDE/GNOME menu (~/.local)
   ./tacx_desktop        # or launch from the app menu
   # Remove launcher: ./uninstall.sh

1) BlueZ session (never sudo the app)
   sudo pacman -S --needed bluez bluez-utils bluez-libs gtk3 libepoxy xz util-linux
   sudo systemctl enable --now bluetooth
   groups | grep -q bluetooth || sudo usermod -aG bluetooth "$USER"   # then log out/in
   rfkill unblock bluetooth 2>/dev/null || true
   bluetoothctl power on
   bluetoothctl show | grep -E 'Powered|Discovering'

2) Runtime libs (tar.gz / AppImage)
   # AppImage is self-contained enough for most Garuda installs.
   # tar.gz: ldd ./tacx_desktop | grep 'not found' || echo "ldd OK"
   # If anything is missing: sudo pacman -S gtk3 libepoxy xz util-linux

3) Wayland blank/crash fallback
   GDK_BACKEND=x11 ./Tacx_Desktop-*.AppImage
   # or: GDK_BACKEND=x11 ./tacx_desktop

4) In-app
   Welcome → Connect on first launch. Demo OFF by default.
   Demo ON only to try UI (devices labeled DEMO — never shown as "found" trainers).
   Quit Zwift/Tacx/MyWhoosh/Wahoo/Rouvy → forget trainer in KDE Bluetooth
   (do NOT OS-pair) → Scan (Tacx or Kickr FTMS) → Connect → ERG.
   Focus / game mode: press G (or header Focus). F11 fullscreen; Esc leaves fullscreen.

Pitfalls: Soft-blocked rfkill; OS pairing; another app holding the link (busy/NOCTRL).
Kickr ERG: allow 3–5 s to settle after Apply. Kickr Bike: Resistance panel stays disabled.
Public FTMS only — no Wahoo proprietary a026* path.
